# 街景定位 浏览器插件（侧边栏版）

**常驻浏览器右侧的侧边栏**：一键截取当前网页 → 本地模型推断地点 → 侧边栏内直接查看地图/候选/纠错。

## 安装（Chrome / Edge，开发者模式）

1. **启动本地服务**（侧边栏依赖它）：
   - 双击桌面 **`启动-街景定位.bat`**（推荐），或手动：
     ```bash
     cd backend && python -m uvicorn app.main:app --host 127.0.0.1 --port 8200
     cd frontend && npm run dev        # 完整界面（含地图）
     ```
2. 浏览器打开 `chrome://extensions`（Edge：`edge://extensions`）
3. 开启右上角**开发者模式**
4. **加载已解压的扩展程序** → 选择本 `browser-extension/` 目录
5. 浏览器工具栏出现图标 → **点击图标即打开右侧侧边栏**（也可右键网页 → "用街景定位分析"）

> 要求 Chrome 114+（侧边栏 API）。若不支持侧边栏，会退化为仅打开完整界面。

## 使用

侧边栏布局（常驻右侧，不消失）：
```
┌─────────────────────────┐
│ 📍街景定位  [截取当前页][↻] │  ← 顶部工具条
├─────────────────────────┤
│                         │
│   完整界面（iframe）      │  ← 地图 / Top3候选 / 双击纠错
│   与网页版一致            │
│                         │
└─────────────────────────┘
```

- **截取当前页**：截当前标签可见区域 → 提交本地后端 → 侧边栏内嵌界面自动跳转到结果（显示地图、Top3候选）
- **↻**：重新加载侧边栏内界面
- 侧边栏**常驻**：切换标签、点其他页面都还在，直到你手动关闭
- **双击地图纠错**：与网页版一致，会把该图作为参考图加入本地检索库

## 与网页版的关系

侧边栏**内嵌了完整网页界面**（iframe 指向 `localhost:5173`），因此：
- 地图、候选列表、置信度、双击纠错、导出等**全部功能一致**
- 顶部工具条额外提供"截取当前页"入口（网页版没有，因为网页无法截浏览器）

## 说明

- 插件**只与本地 127.0.0.1 通信**（8200 后端 + 5173 前端），不外传
- 后端 CORS 已放行 `chrome-extension://` 来源
- 需要本地服务运行；未启动时侧边栏会提示

## 局限

- 整页截图当前退化为**可见区域**（完整滚动拼接较复杂，后续可加）
- 侧边栏依赖本地前端 5173（`npm run dev` 或打包后 dist）；若只起后端不起前端，侧边栏会显示占位提示
