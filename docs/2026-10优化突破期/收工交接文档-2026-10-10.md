## 二、怎么跑起来

### 一键（推荐）
双击桌面 **`启动-街景定位.bat`**：
1. 清理 8200/5173 端口 → 2. 启后端（预热 40-90s）→ 3. 启前端 → 4. 打开 http://localhost:5173
5. 窗口内附**插件安装提示**

### 手动
```bash
cd backend  && python -m uvicorn app.main:app --host 127.0.0.1 --port 8200
cd frontend && npm run dev        # → http://localhost:5173
```

### 浏览器插件
`chrome://extensions` → 开发者模式 → 加载已解压的扩展程序 → `browser-extension/`
（需 Chrome 114+；桌面 `street-geolocator-插件-v11.zip` 备用）

**依赖**：Python 3.13（torch/transformers/openai 等，见 `backend/requirements.txt`）、Node.js。
**模型权重**（不在 git，需自备）：`backend/models/streetclip`（1.6G）、`backend/models/clipb16`；
DINOv2 权重走 HuggingFace 缓存；图库特征 `backend/data/dinov2_gallery/features.npz`（脚本生成）。

## 六、已证伪的路径（勿重复踩坑）

| 方法 | 实测 | 结论 |
|---|---|---|
| 换更大 CLIP（ViT-H 986M） | 50.6%（与175M打平） | 无收益 |
| OSV5M 回归 GPS | 37.1% | 回归弱于文本匹配 |
| MegaLoc 小库检索 | 18% | 需百万级图库 |
| 4 模型融合 ORACLE | 57.3% 上限 | 错误高度重叠 |
| 剔除 China / 换 prompt 复核 | 0 救回 / 净 -2 | 无效 |
| 提示词模板 A/B | ±1 张噪声 | 无显著收益 |
| 半球约束 / 车道方向 | 64% / 40.4%（低于随机） | CLIP 无此能力 |
| GSV 照片量加权 | 净 -5 | 双重计数 |
| OCR / NDVI / 标线 / 城市池扩大 | 历史 +0pp / Top1 下降 | 已证伪 |

**根因**：凡"用 CLIP 额外问一个问题"的优化全部无效；有效提升只能换证据源（判城市）或换特征源（DINOv2 图库）。
