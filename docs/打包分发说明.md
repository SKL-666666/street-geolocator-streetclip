# Street Geolocator 打包分发说明

## 一、给使用者的说明（最重要）

1. 把整个 **`StreetGeolocator` 文件夹** 拷给对方（或打包成 zip 发送），里面有：
   - `StreetGeolocator.exe`（程序本体）
   - `_internal\`（运行库与数据，**不要动它**）
2. 对方双击 `StreetGeolocator.exe`：
   - 会弹出一个黑色控制台窗口（**不要关闭它**，关闭 = 退出程序）
   - 稍等 1~3 秒会自动打开浏览器进入使用页面
   - 若浏览器没自动打开，手动访问 `http://127.0.0.1:8000`
3. **首次使用**：页面会显示"配置你的 LLM API Key"——对方填自己的 Key（如智谱开放平台 open.bigmodel.cn 申请的），点"保存并开始使用"即可。
   - Key 只保存在本机 `StreetGeolocator\data\llm_key.json`，不会上传任何服务器
4. 每个人**用自己的 Key** 计费，互不影响。
5. 换一台电脑使用 = 把整个文件夹拷过去重新填 Key 即可。
6. 关闭程序：关闭黑色控制台窗口（或 Ctrl+C）。

## 二、常见问题

| 问题 | 解决 |
|---|---|
| 双击没反应 / 秒退 | 控制台会显示错误信息。最常见原因：杀毒软件拦截（添加信任）、路径含中文/空格异常（放到英文路径试试）|
| 页面打不开 | 确认控制台窗口在运行；手动访问 http://127.0.0.1:8000 |
| 分析报"令牌已失效/401" | API Key 填错了，或余额不足：到平台重新生成 Key，在设置页重新保存 |
| 分析慢/超时 | 第三方平台繁忙（智谱高峰），重试按钮可直接重跑同一张图 |
| 想换平台（通义/豆包/DeepSeek 等）| 设置页填写对应平台的 Base URL 和模型名即可（OpenAI 兼容接口）|

## 三、重新打包（给开发者）

```powershell
cd backend
.\.venv\Scripts\python.exe -m pip install pyinstaller
# 确保前端已构建
cd ..\frontend && npm run build
cd ..\backend
.\.venv\Scripts\python.exe -m PyInstaller --clean --noconfirm street-geolocator.spec
# 产物：backend\dist\StreetGeolocator\
```

打包内容：
- 后端（FastAPI）+ 前端静态页（单端口 8000 全包）
- MixVPR 本地视觉先验（torch CPU，约 500MB）+ 20 城画廊 + 罗马街景索引
- 不含任何 API Key；用户首次启动自行配置

## 四、分享方式对比（给分发者）

| 方式 | 适合 | 说明 |
|---|---|---|
| 拷文件夹/zip 给对方 | 熟人、离线、每人独立 Key | 文件夹约 800MB~1.5GB（含 torch）|
| 局域网部署（`--host 0.0.0.0`）| 同一 WiFi 内多人共用 | 只有一份 Key，所有人共用该 Key 额度 |
| 云服务器 | 公网长期使用 | 需自行处理 Key 与网络环境 |

## 五、数据与隐私

- 用户上传的照片仅在本机处理；调用第三方大模型 API 时图片会发送给该平台（这是 LLM 分析的必经环节）
- 本机保存：任务记录（`data\tasks.json`）、原图（`data\uploads\`，用于失败重试）、用户 Key（`data\llm_key.json`）
- 删除任务记录会同步删除对应原图；Key 可在数据目录手动删除（删除后回到"首次配置"状态）

## 六、Key 隔离（重要）

- **代码中不内置任何 API Key**；只有两种配置来源：开发版 `backend/.env`（开发者自己用）和设置页写入的 `data/llm_key.json`（每个使用者自己的）
- **打包版（exe）完全不读取 .env 文件**：即使分享文件夹里误带了开发版的 `.env`，程序也会忽略它——对方只能通过设置页填写自己的 Key，无法使用开发者的 Key
- **未配置 Key 时无法推理**：程序会直接提示"请先在设置页填写自己的 API Key"（分析请求返回 503），绝不会回退到任何默认/示例 Key
- **分享前请自查**：不要把 `backend/.env`、`data/llm_key.json`、`data/tasks.json`（含历史分析记录）一起发出去；打包产物 `dist/StreetGeolocator/` 本身不含这些文件
