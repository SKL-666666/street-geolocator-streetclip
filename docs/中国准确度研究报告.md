# 为什么"仅中国大陆"模式看起来远不如"全世界"？—— 定量研究报告

> 版本：v1 · 2026-08 · 基于 30 张真实中国城市图片（成都/上海/西安/重庆/杭州 × 6）的对比实验

## 一、结论先行（TL;DR）

1. **城市级准确率其实一样**：30 张真实中国图，`cn` 模式与 `world` 模式的城市 Top1 命中率**同为 79%**。
2. **"中国差"主要是感知差异**：`world` 模式有"国家级"中间档（国家命中 93%），城市猜错但国家正确时用户觉得"对了"；`cn` 模式没有中间档，城市错 = 全错 = 直接显示在地图上。
3. **但中国场景存在真实的额外困难**：LLM 大城市偏见 + 无文字同质化 + 零本地支持（先验/索引/街景全缺）。
4. **最刺眼的问题：LLM 自信地猜错**——猜错时置信度高达 0.6~0.9（"电视塔夜景=上海"、"球形建筑=上海"），常规阈值/复检都拦不住。

## 二、实验设计

- 数据：30 张真实中国城市街道/街景照片（Bing 图片搜索下载，5 城 × 6 张：成都/上海/西安/重庆/杭州）
- 每张图分别跑 `fast` 档的 `cn` 与 `world` 模式（glm-4.6v-flashx）
- 命中判定：Top1 候选城市名包含真值城市

## 三、结果

| 指标 | cn 模式 | world 模式 |
|---|---|---|
| 城市级 Top1 | **79%** (23/29) | **79%** (23/29) |
| 国家级 Top1 | —（强制中国）| **93%** (27/29) |
| 城市错但国家对 | — | 4 张（"看起来对"的来源）|

### 失败样本拆解（cn 模式 6 错）

| 图 | 真值 | LLM 输出 | 置信度 | 失败类型 |
|---|---|---|---|---|
| 成都_1（夜景+电视塔）| 成都 | 上海 | 0.60 | **大城市偏见**：电视塔=东方明珠 |
| 成都_3（现代化夜景）| 成都 | 杭州 | 0.60 | 无文字纯景观硬猜 |
| 成都_6（天际线）| 成都 | 上海 | 0.70 | 大城市偏见 |
| 杭州_5（球形建筑）| 杭州 | 上海 | **0.90** | 大城市偏见：球形=东方明珠（杭州也有日月同辉）|
| 上海_5 | 上海 | 北京（兜底）| 0.01 | **LLM 超时**降级（平台波动）|
| 重庆_2 | 重庆 | 北京（兜底）| 0.01 | **LLM 超时**降级 |

### 文字依赖度（cn 模式）

- 有可见文字 6 张 → 命中 83%
- 无文字 23 张 → 命中 78%
- 结论：本测试集（图库图）文字不是主因；**真实街景中文字更重要**（合成招牌图测试 3/3 命中）

## 四、根因分析（按影响排序）

### 1. LLM 对中国城市的地标/特征知识不可靠 + 大城市偏见（主因）
- "电视塔/夜景/球形建筑/摩天楼"在中国 300+ 城市普遍存在（成都天府熊猫塔、杭州日月同辉、广州塔、天津天塔），但 flashx 看到就猜上海/北京/杭州
- 猜错时置信度 0.6~0.9，说明模型"很自信"——不是不确定性，是**系统性偏差**
- 同图不同模式/不同采样结论不同（成都_3：cn 猜杭州、world 猜布拉格；杭州_5：cn 猜上海、world 猜对）——**单次采样随机性大**

### 2. 无文字时的城市判别几乎不可能（结构性）
- 中国城市景观高度同质化（同款招牌/路灯/柏油路/住宅楼），仅靠视觉几乎无法区分城市
- 可区分的信号（方言文字/饮食招牌/车牌省份字/地形）在多数街景照片中不出现

### 3. cn 模式零本地支持（结构性缺失）
- MixVPR 画廊全外国城市 → cn 模式跳过先验 → 无本地粗筛
- 街景索引只有罗马 → 中国无街道级候选
- KartaView 中国无数据/连不上 → 街景回查 + LLM 复检在中国失效
- 超时降级后只剩"北京默认点"

### 4. 兜底城市固定（结构性）
- LLM 只判"中国"未判城市时，`_ensure_city_hypotheses` 补城表人口前 3 = **上海/北京/广州**
- 城市级命中率被这个默认值锁死（图在成都却给上海）

### 5. 平台超时波动（偶发）
- 2/30 张 LLM 超时（flashx 高峰 20s+）→ cn 模式无本地兜底 → 北京默认点

## 六、已实施的修复（验证结果）

1. **cn prompt 反大城市偏见**：明确"电视塔/球形建筑/天际线/夜景单独出现不足以判定一线城市"；要求优先使用可区分线索；无强线索时给低置信多候选
2. **cn 模式强制双采样**：并行两次采样取并集
3. **中国少样本示例 ×2**（提示词严格分离）：川渝火锅/闽粤骑楼两个中国示例——cn 模式用中国提示词（公共头+中国少样本+公共尾+范围指令），world/no-cn 用全球提示词（含 4 个全球少样本），互不污染（有 pytest 断言）
4. **中国城市特征档案 Top60**（知识库严格分离）：独立 `geokb/cn_cities.py`（60 城×特征关键词：饮食/建筑/地形/地标）+ `geokb/cn_engine.py` 匹配引擎；scene 线索命中 ≥2 关键词 → 注入城市假设（0.3~0.7 置信，精确坐标）；不修改全球 89 国引擎

### 验证结果（30 张真实中国图，同批数据重跑）

| 版本 | Top1 城市命中 | Top2 命中 |
|---|---|---|
| v1（单采样，修复前）| 79% (23/29) | — |
| v2（双采样 + 反偏见）| 93% (27/29) | 93% |
| **v3（+中国少样本 + 城市档案）** | **93% (27/29)** | **97% (28/29)** |

- 城市档案把"候选包含正确城市"从 93% → 97%（成都_5 的成都进入 Top2）
- 剩余 1 张失败（成都_6）：纯夜景天际线、零可区分线索——该类图人类也难以判断

**结论：cn 模式城市命中 93%（Top1）/ 97%（Top2），与 world 模式国家命中率（93%）持平或更高。**

## 七、给用户的建议

- **判定"准不准"时**：对比同图 world 模式的国家命中（93%）才公平；中国场景请以"候选列表含正确城市"（Top3）为口径
- 真实街景照片**有招牌/车牌**的命中率远高于图库夜景图（文字直出是强信号）
- 已启用双采样：同一张图会展示最多 2 个城市的并集候选，命中概率提升（实测 79%→93%）
- 纯夜景/天际线无任何文字的图，人类也难以判断城市——请裁剪招牌/路牌局部后重传
