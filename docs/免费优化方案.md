# 免费优化方案清单（便捷 × 收益优先）

> 约束：不新增任何付费服务（不用付费 API、不租 GPU、不买数据）。
> 排序依据：收益 / 工作量 / 便捷度。所有方案用到的都是现有 GLM API（按量计费，
> 每图几分钱级）、免费开源模型与免费数据源。
>
> **状态：六项全部完成（2026-08）。实施详情见各节末尾。**

---

## 方案 1：评估闭环（自动评测 + 免费测试图集）—— 先修"尺子"

**现状问题**：所有改进都是"感觉变好了"，没有量化证据；改 Prompt 可能悄悄变差而不知。

**做法**：
- 从 AI_GeoDetect 仓库免费拉取带真值的街景图（已探明：`webapp/static/examples/{budapest,kyiv}/*`、
  `test photo/*`，共 25+ 张，GitHub 可达），再加 Mapillary 免费 token 随机采样扩充
- 写 `evaluate.py`：批量跑管线 → 输出**国家 Top-1/Top-3 准确率 + 证据矩阵命中率 + 单图耗时/成本**
- 支持"开/关 KB、开/关工具"的**消融对比**（A/B 测试架构），入 CI 回归

**收益**：以后每一次优化都有数字背书；直接暴露"哪类图 LLM 总认错"。
**工作量**：1~2 天。**成本**：0（每图 2 次 GLM 调用，20 图 ≈ 几毛钱；可用 mock 跑管线测试）。

---

## 方案 2：线索提取强化（Prompt 手术）—— 免费提升 KB 命中率的最大杠杆

**现状问题**：实测发现 KB 命中率不稳定——同一张基辅图，有时提取出"乌克兰语+西里尔+右舵"
（KB 完美命中），有时漏掉语言/驾驶侧（KB 归零）。**KB 的上限 = LLM 提取质量**。

**做法**（全部是提示词工程，不动架构）：
- 强制 `driving_side`：必须给出 left/right/unknown，unknown 时必须写明"看不到车辆/行人，无法判断"
- 新增独立 `scripts` 字段（文字体系），与语言分开提取
- 路牌/招牌提取要求"描述形状+颜色"（喂给 SIGN_KEYWORDS 匹配）
- Prompt 加 2~3 个少样本示例（few-shot），演示"证据→字段"的正确映射
- 可选：双次采样（同图跑 2 次取并集）——每次多花一次调用，约 1 分钱，KB 命中率显著提升

**收益**：KB 从"有时有用"变成"稳定有用"，直接提升国家级精度与幻觉抑制效果。
**工作量**：0.5~1 天。**成本**：0（可选双次采样每图 +1 分钱）。

---

## 方案 3：国家档案扩充 + 新判别维度 —— 知识库变厚

**现状问题**：档案只有 50 国 × 8 维度，路牌关键词 10 条。很多国家的强线索缺失。

**做法**（纯数据录入，GeoGuessr 社区公开知识）：
- 国家扩充到 80~100 国（补：拉脱维亚/立陶宛/爱沙尼亚/斯洛文尼亚/马来西亚/新加坡/智利/秘鲁/哥伦比亚/肯尼亚/尼日利亚…）
- 新维度：**路桩样式、电线杆/输电线塔样式、消防栓颜色、井盖样式、道路标线颜色、限速牌样式**、
  车辆常见品牌（本地车 vs 进口车比例）
- 路牌关键词扩充（黄色菱形→北美/日本/澳新；蓝色高速→西班牙/荷兰/比/英…）

**收益**：证据矩阵覆盖更广；小众国家不再"未核实降信"。
**工作量**：1~2 天。**成本**：0。

## 方案 4：结果缓存 + 批处理 —— 省钱省时的复利

**现状问题**：同一张图分析两次花两份钱；一次只能传一张。

**做法**：
- 上传时算图片感知哈希（dHash/pHash，PIL 自带能力），命中缓存直接返回历史结果（可配置 TTL）
- 前端支持一次拖入多张 → 后端排队批量分析 → 结果列表页
- 任务历史页（已有 tasks 列表 API，补个 UI）

**收益**：重复分析零成本；多图工作流效率翻倍。
**工作量**：1 天。**成本**：0（且省未来的 API 钱）。

---

## 方案 5：本地 MixVPR 第二意见（CPU 免费地理先验）—— 不用建库的城市级先验

**现状问题**：LLM+KB 都只能到国家级；没有"位置感"。

**做法**：
- MixVPR（ResNet50 骨干，512 维，25M 参数）在数亿张带 GPS 街景上训练过
- 本地 CPU 推理 1~2 秒/图（无需 GPU），PyTorch 权重从 GitHub 免费下载（本机可达）
- 输出"世界哪里最像"的热点（全球网格投票），与 LLM 假设、KB 证据三方融合
- 不建任何索引库，纯粹用模型的"记忆"

**收益**：城市级先验（相当于免费的方案 C）；对 LLM 从未见过的国家也有判断。
**工作量**：2~3 天。**成本**：0（CPU + 免费权重，模型 ~50MB 级）。

---

## 方案 6：KartaView 免 key 街景源接入 —— Phase 2 的免费数据层

**现状问题**：Mapillary 需要申请 token；Phase 2 检索库数据源单一。

**做法**：
- KartaView（原 OpenStreetCam）API **完全免费无需 key**（调研已确认，仅端点格式需再摸一次）
- 实现为 streetview provider 接口的第二个实现，与 Mapillary 并列、可切换/合并
- 顺带把它的照片 URL 协议接进候选回查（有真实街景缩略图展示）

**收益**：Phase 2 建库数据源翻倍；候选回查不再依赖 Mapillary token。
**工作量**：1~2 天。**成本**：0。

## 汇总对比

| 方案 | 收益 | 工作量 | 成本 | 状态 |
|---|---|---|---|---|
| 1. 评估闭环 | ★★★★★（一切改进的度量尺） | 1~2 天 | 0 | ✅ 23 张图集 + evaluate.py（消融/限流/历史） |
| 2. 线索提取强化 | ★★★★☆（KB 命中率直接翻倍潜力） | 0.5~1 天 | 0 | ✅ scripts 字段 + few-shot + 强制 driving_side |
| 3. 档案扩充 | ★★★☆☆（覆盖更广） | 1~2 天 | 0 | ✅ 85+ 国 + 路桩/消防栓/电线杆/标线/车牌 5 新维度 |
| 4. 缓存+批处理 | ★★★☆☆（省钱省时） | 1 天 | 0 | ✅ 感知哈希缓存（实测 0.05s 命中）+ 多图批量 |
| 5. MixVPR 先验 | ★★★★☆（解锁城市级） | 2~3 天 | 0 | ✅ 4096 维权重（512 维被 GD 封锁）+ 20 张画廊 + 阈值 0.3 |
| 6. KartaView 接入 | ★★★☆☆（Phase 2 数据地基） | 1~2 天 | 0 | ✅ 免 key 端点实测（埃菲尔 8 张）+ 半径自动放大 |

**量化结果（23 张真值图集，GLM-4.6V）**：
- 国家 Top-1：**40% → 45%**（同 18 张子集对比 40% → 46.7%，含捷克别名修正）
- KB 覆盖：100%（证据矩阵稳定产出）
- 单图平均 ~44s，LLM 调用 1 次/张
- 测试套件 45/45 通过

**诚实声明（重要）**：评测图集与 MixVPR 画廊同源（都来自 AI_GeoDetect），
先验的"19/20 城市命中"是自匹配（相似度 1.00），**独立城市精度尚未验证**——
子代理的留一法测试显示 4 个欧洲首都跨城判别弱（0.10 相似度），阈值 0.3 已保护。
真正验证需画廊与测试集来自不同城市（Phase 2 数据管线）。

**推荐组合**：先做 **1 + 2**（两天内看到量化提升），再按兴趣做 3 或 5。
